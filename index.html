📖 使い方ガイド

      


        

          
🔍 求人検索

          

            左の絞り込みパネルから条件を選ぶと、リアルタイムで結果が更新されます。

            エリア・職種・各種条件・希望年収で絞り込みができます。
          

        


        

          
➕ 企業の追加方法

          
    
            
  1. 「企業追加」タブで情報を入力して「JSONを生成」ボタンを押す
    2. 
            
  2. 生成されたJSONをコピー
    3. 
            
  3. GitHubの companies.json を開いて編集
    4. 
            
  4. 配列の最後の } の後に , を追加してJSONを貼り付け
    5. 
            
  5. 「Commit changes」で保存→数分後に自動反映
    6.

  "jobType": ["施工管理", "エンジニア"],
  "location": "勤務地",
  "area": "担当エリア",
  "nearestStation": "最寄り駅",
